LIVE · REAL TRAFFIC
Your health check is either working or it's decoration.

Two byte-identical Node services are running on Zerops right now. Same code, same build, deployed twice. One has healthCheck in its zerops.yml. The other doesn't. A load generator hits both over the private network at 20 req/s, continuously. Press a button and break them the same way.

THE ONLY DIFFERENCE
NAIVEzerops.yml
- setup: naive
  build:
    base: nodejs@22
    deployFiles: [apps/victim]

  # no deploy.readinessCheck

  run:
    start: node apps/victim/index.js
    # no run.healthCheck
    #
    #
    #
HARDENEDsame files, same build
- setup: hardened
  build:
    base: nodejs@22
    deployFiles: [apps/victim]

  deploy:
    readinessCheck:
      httpGet: { port: 3000, path: /healthz }
  run:
    start: node apps/victim/index.js
    healthCheck:
      httpGet: { port: 3000, path: /healthz }
      execPeriod: 10s
      failureTimeout: 10s
